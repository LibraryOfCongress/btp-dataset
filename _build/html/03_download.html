Get the Data#

How to open#

Details about formats and the contents of this dataset are at About the Data.

This dataset as CSV, JSON, and Parquet. Excel may have trouble opening and displaying the CSV, which is intended to be opened by computational analysis tools.

Download#

1. Download from loc.gov#

This dataset is available for download in three formats, as ZIP files, at By the People comprehensive transcription data package.

  • 2026395156_csv.zip - 239 MB (1.2 GB uncompressed)

  • 2026395156_json.zip - 251 MB (1.6 GB compressed)

  • 2026395156_parquet.zip - 186 MB (195 MB compressed)

2. Download using Jupyter notebook tutorial#

See the Tutorial Instructions to begin a tutorial to that includes downloading and analyzing the transcriptions using Python.

3. Download source datasets from the Selected Datasets collection#

This dataset is created by combining smaller datasets from each completed By the People campaign. These source datasets can be individually downloaded from the Selected Datasets Collection. The source datasets do not contain all of the same metadata fields included in the aggregated dataset, but they do each include the same transcriptions, basic logistical metadata including URLs to the primary image files (usually JPEG), and a README file. Eash source dataset can be downloaded directly from the Selected Datasets collection link above.

The full aggregated dataset, available as described in the other options above, includes additional metadata and image URLs gathered via the loc.gov API.
