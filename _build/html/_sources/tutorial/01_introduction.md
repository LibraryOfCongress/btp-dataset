## Tutorial Instructions

This coding tutorial provides an example of data processing and visualization using the **By the People Comprehensive Transcription Data Package**. The code, shared in {doc}`02_visualizing_sentiment`, fetches the dataset, runs sentiment analysis, and visualizes the sentiment analysis. The code in this tutorial can be modified to replace sentiment analysis scores with any other type of scores, and similarly visualize the results.

### Downloading the Tutorial

The Jupyter notebooks can be downloaded from the Github repository at [Library of Congress btp-dataset GitHub repository](https://github.com/LibraryOfCongress/btp-dataset). You can also use the download button near the top of the tutorial. 

Or, you can download or clone the entire Library of Congress btp-dataset repository, which contains the tutorial. The notebook is located in the `tutorial` directory of the repository. 

### Installing Requirements

In order to properly run these notebooks, make sure that the appropriate Python libraries are installed. The list of required Python libraries is on the notebook under the **Prerequisites** heading.


### Running the Tutorial

You'll need to have a computer or other environment with Python and Jupyter Notebook. 

There are several methods for opening the notebook file once you have downloaded it. For example: from your computer or other computing environment, navigate to directory holding the `02_visualizing_sentiment.ipynb` file, then run the command `jupyter notebook`. This will launch the Notebook Dashboard in a web browser.
